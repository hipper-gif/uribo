# 美容部 FY2026 上半期実績と下半期目標（報告書一式）

本番: `~/twinklemark.xsrv.jp/public_html/uribo/`（Nicolio セッションゲート）。2026-10-13 美容部ミーティング（オーナー・マネージャー向け）で使用。

| ファイル | 用途 | 印刷 |
|---|---|---|
| `hanki_fy2026_exec.php` | 社長提出用の本文（2部構成: 上半期はこうでした／下半期はこうします。タイル・売上の行き先バー・月別利益グラフ） | A4縦5枚・第2部で改ページ |
| `hanki_fy2026_year.php` | 別紙①: 一年通し「目標・実績・純利益」表（売上=前年/期初目標/下期修正/実績/達成率、経費=前年/計画/実績、純利益=前年/計画/実績。店ごと1枚＋部門計） | A4縦3枚 |
| `hanki_fy2026_pl.php` | 別紙②: 上半期の科目別・月別損益表（うりぼー形式・グループ見出し・構成比） | A4横3枚 |
| `hanki_fy2026.php` | スタッフ版（詳細・損益分岐点・定着KPI） | — |

生成器（`beauty_monthly_data` を nicolio-api で読んで HTML を作る。`scripts/.env` のトークンを使う）:
- `make_year.py` → `year.php`（一年通し表。下半期の計画利益は MODEL 定数＝10/1確定の変動費率・固定費/月）
- `make_pl.py` → `pl.php`（上半期損益表）＋ exec.php の明細表を別紙リンクに置換
- `restyle.py` → exec.php に視覚ブロック（タイル・行き先バー・利益グラフ）を注入（1回きりの変換。再実行不可）

数字の約束: 上半期純利益 寝屋川138.5／守口27.1／計165.6万（賞与22万を9月計上後）。各生成器は assert で本文の値と一致を確認する。
来期（FY2027）に同じ形で出すときは、生成器の fiscal_year と MODEL を更新して再生成し、scp で本番へ置く（deploy.sh の対象外）。
